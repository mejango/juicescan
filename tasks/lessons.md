# Lessons

- **Preserve raw decimal text and focus through form renders.** A number input rebuilt on every keystroke loses its trailing decimal point and focus. Use a text input with a decimal keyboard, central conversion/validation, and scoped focus/caret restoration when dependent controls require a full render. Prove sequential typing, mid-value edits, native unit clicks and one-click navigation in Chromium; retain existing split locks while custom text is incomplete. (2026-10, kmac88 custom ruleset duration feedback.)

- **Never chain two range-based `sed -i` deletes on one file** — the first edit shifts line numbers, so the second range is wrong and silently clips a neighboring function. Use the Edit tool, or one grep-anchored deletion. Catch: build + `vitest` immediately after a structural delete. (2026-06, removing an orphaned fn in discover.js clipped `infoItem`.)

- **Validate API numeric fields against their display domain.** Safe integers can still exceed ECMAScript Date bounds; reject unsupported timestamps before pagination state changes. Preserve tiny positive chart densities rather than imposing a visual floor, and explicitly label missing stake/recipient attribution. Receipt count coherence and partial-record rendering are enforced by the Entries parser/render regressions. (2026-10-11, Defifa Entries review.)

- **Keep market copy plain and keep audit identity in audit details.** Do not use middot separators in visible copy; native ranges captions stay concise, without snapshot blocks. Remove redundant header glossary links rather than adding presentation switches. Native-caption and visible-copy regressions enforce this preference. (2026-10-11, user presentation correction.)

- **Protocol identity is not application identity.** A verified Defifa hook supplies tier names, per-tier prices, supply and lifecycle state; it does not prove Metalog numeric ranges or justify Metalog navigation. Keep generic NFT displays free of curve information and API clients. Mixed-price/nonnumeric-name and consumer-independence regressions enforce this boundary. (2026-10-11, user scope correction.)

- **Audit ancillary RPC clients as well as the main project reader.** ENS lookups in address fields and connected headers must use the shared mainnet client, preserving explicit user overrides. Real viem forward/reverse HTTP regressions enforce Center defaults and prevent a dedicated provider from bypassing the policy. (2026-10-12, connected-wallet live proof.)

- **Protocol-specific calldata does not imply protocol-specific checkout styling.** Native Defifa uses the existing shop preview, cart, tier cards and payment layout; isolate differences in the submission adapter, phase/quote evidence and review text. Enforce a preview-and-cart parity regression rather than replacing the purchase surface with a navigation-only link or quantity table. (2026-10-12, user checkout correction.)

- **Qualify action-absence regressions in a phase where the old action would exist.** A closed mint phase cannot prove removal of a duplicate mint form. Revert the owning caller and confirm the regression fails, then restore it; source review and passing fixtures alone do not prove the gate catches the bug. (2026-10-12, Cash out presentation review.)

- **Connection is part of the draft lifecycle.** Never restore values captured before an awaited wallet connection over edits made while it waits. Preserve the existing visible draft through redraws and prepare from its latest getter; event and no-event regressions enforce this without another state machine. (2026-10-12, shared checkout connection review.)

- **Successful metadata does not prove decodable artwork.** Creator SVG can contain malformed XML despite a valid data URI. Keep gateway retries in the shared media source owner, then restore a placeholder on final image failure across cards and selected thumbnails; never leave a broken icon or rewrite creator SVG to claim success. Real-browser malformed XML and stale-image error regressions enforce this. (2026-10-12, native checkout live qualification.)

- **Programmatic mode changes need the same formatting as manual selection.** Update inline selector width in the shared mode presentation owner, not only change callbacks. Keep empty diagnostic boxes invisible from their first render, while nonempty errors remain readable. Delayed-identity and native/ordinary mode browser regressions enforce both. (2026-10-12, Pay chevron/loading screenshot correction.)

- **Moving an import can reorder module evaluation and expose a cycle.** component-base → tx-pretty-args → permissions-component → component-base worked only because app.js happened to import the widget first; moving the widget map into a lazy module made `PERMISSION_IDS` undefined at startup. Unit tests run each module graph differently and passed. Keep shared data in import-free modules, and run the browser suite after every change to import structure; `lazy-chunks.spec.js` boots the real bundle from a gateway path. (2026-10-20, load-size split.)

- **Use explicit absolute plan destinations in shared workspaces.** Before writing a task plan, set the isolated checkout as cwd and name its absolute destination. A plan checker may need root cwd; that does not move the plan's owning file. Never overwrite another task's root plan while preparing a local append. (2026-10-24, delegated convergence work.)
